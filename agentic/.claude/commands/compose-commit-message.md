Look at the currently staged changes using `git diff --staged` and compose a commit message for them.

Follow any commit message conventions defined in CLAUDE.md if present. Otherwise:
- Use the imperative mood in the subject line (e.g. "Add", "Fix", "Remove")
- Capitalize the first letter of the subject line
- Keep the subject line under 72 characters
- Add a body when the change warrants more explanation, separated from the subject by a blank line

Do not include "Co-Authored-By" or any AI attribution in the message.

Present the commit message in a fenced code block so it can be copied directly.
